# Official Qt for Python Documentation Index

官方权威文档入口与常用模块速查：

- **官方门户**：[Qt for Python (PySide6) Documentation](https://doc.qt.io/qtforpython-6/)
- **API 参考手册**：
  - `PySide6.QtWidgets`：桌面经典小部件库（QMainWindow, QWidget, QDialog, QLayout 等）
  - `PySide6.QtCore`：核心非 GUI 功能（QObject, Signal, Slot, QThread, QTimer, QUrl）
  - `PySide6.QtGui`：底层图形能力（QColor, QPalette, QFont, QIcon, QPainter）
  - `PySide6.QtUiTools`：动态 UI 加载器（QUiLoader）
- **官方示例库**：
  在安装了 PySide6 的环境中，可通过官方示例目录直接运行并查看源码：
  ```bash
  python -m PySide6.examples
  ```
